# 5.1 出片标准

基准标识 `5.1.4-2026-11-20`。完整强制条款以仓库根目录 `AGENTS.md` / `模板输出约束标准.md` 为准；本文件是同一标准的出片摘要。文案与时间码按当期变化，视觉基线保持。用户当前明确修改优先，其余条款继续生效。

5.0 的《买房先做减法再做加法》仍可作结构与节奏参考，但其暖白卡面、暖金当前词和沙金标题强调已被 5.1 取代，不能再当色彩标准。5.1 样张见 `previews/current/`。

## 1. 整体效果

1920×1080 横屏，正片 30fps，独立片头 50fps。清晰通透的中国住宅 / 城市实景作背景；前景是墨蓝·电光的中深透明玻璃卡，语义色只出现在描边、数字和图标上。深色卡内用冷白字，层次来自微渐变和语义描边，无颗粒、无扫光。中性白平衡，不用整屏黄绿、褐黄或青蓝滤镜。

普通卡片是规整圆角矩形，整组轻透视后停稳。不能把 38 种 MG 统一改成一种长方形清单。内容短时优先 5 款小卡组合。

## 2. 玻璃、色彩和文字

材质以 `tokens.ts / toneMat / glassMat / GlassEdge` 为准，默认色板 `inkBlue`。模糊为 `blur(18px) saturate(1.15)`。禁止暖白卡、土黄底、棕粉大面积填充和金色标题。

标题强调 `{词}` 使用 `HILITE`（`#BCD6FF` / `#1F56C4`）。卡内字走 CSS 变量 `--ink / --sub / --acc`。字体：片头江城律动宋 + Health；正片 PuHui Black 标题、Health Bold 正文及字幕。缺字体必须补齐。

正片字幕 36px，横向对齐 MG 卡片组中心 x=864，冷白 `#F5F8FC`，当前词冰蓝 `#9CC4FF`，墨蓝半透明底部胶囊，距底 44px，强制单行（一句/一个自然停顿一组，跟台词节奏显示，每组 ≤ 31 个全角汉字，超长在停顿处拆组，不许两行），无下划线。详见 AGENTS.md 第 4 节。

## 3. 文本框内抠图

与 5.0 相同：按卡语义决定主体，真实照片质感，透明通道有效，边缘干净，`objectFit: contain`，与文字净距 ≥ 24px。不是白底矩形或截图。需要时用 `cardCutout`。

## 4. 连接线、箭头与空间运动

卡片先落位再连线。入场 16 / 18 / 20 / 12 帧，单调、无回弹。箭头复用 `GlassArrow`。整组轻推后固定。不得持续呼吸或镜尾还在变形。

## 5–6. 片头、开头与片尾

片头与正片可拆开制作，只交代做哪段就只出哪段。独立片头 50fps、纯画面；整片在片头时段也不显示字幕。完整成片保留原声时钟，不得把正片整体后移一个片头长度。片尾固定 `outroHost`，使用小滕形象，互动靠姿势、气泡、弹卡，不加关注引导文字。细节见 AGENTS.md 第 7 节。

## 7. 选版与出片门槛

42 款共用材质与检查（含 4 款图片动效组件）。短内容优先小卡。大卡只放图或图表，纯文字进小卡；不得选用已退役的纯文字重卡；户型用随包自绘素材；字阶取自 `CARD_TYPE` / `CHART_TYPE`；禁止近黑文字。细则见 AGENTS.md 第 3B 节。卡面内容守卫（第 3C 节）：卡面不写占位字（示意/占位/标题/文字/示例/xxx/TODO）；大圆大卡不能只有一两个字，枢纽圆放图标 + 标题 + 补充行；长条卡（宽 ≥ 600px 或 ≥ 3:1）按内容定宽并带图标或补充行，内容实占宽度 ≥ 40%；卡面只用墨蓝·电光玻璃色（不棕、不纯灰、不实心），风险红为酒红。正式输出前必须 `npm run verify` 通过（含可读性/字阶），检查片头预览与正片代表帧，合格后直接导出；用户要求先审看时按其要求执行。

5.1.4 视觉精致度：字阶按 `CARD_TYPE` 贴合卡面；连线用冰蓝/银芯光影线（A→线→B）；入场分层并带轻度透视，无闪烁。细则见 AGENTS.md 第 3E 节。

5.1.5 图文动效与去繁（AGENTS.md 第 3F 节）：片头按 skill「小滕片头风格模板」（ASCII 渐变背景、住宅抠图接力、文字/房子交换、首句结束跟词落红章，片头全程无字幕），只覆盖口播第 1 句；卡面一词/一数 + 至多一行副句，按文字自动适配、边距随字号；按逻辑飞入（fly / wipe / blur / depth / flip / count），仅位移缩放轻过冲 ≤6%、20 帧精确落位、不透明度单调；饰线与卡圆角同心并按角色变化；图片动效组件 `imageFrame3D` / `imageSwap` / `imageGrid` / `imageCutout`，图按本镜口播关键词生成，图片主导镜头 ≥ 1/3、纯卡连续 ≤ 2。

## 8. 缺素材时由 AI 完成取材

背景以视频为主、生成图为辅。无用户视频时，AI 联网寻找免费高清实景，优先航拍或有质感镜头，禁止随手手机拍。全屏图片只在能讲清关键语义时使用，合计不超过正文画面 25%，卡内嵌图另计。列举和对比用图片框 + 文字标题。执行细节见 `正片/references/素材与生图规则.md` 与 AGENTS.md 第 8 节。

## 计划期约束（5.1.3 起，写镜头表时就定，`npm run plan:check` 播前静态检查）

- 卡面文字（标题/补充行/标签）只用本镜口播里的词，不写示意/示例/占位/标题/文字；≤4 字的词必须原样在口播里。
- 每张卡绑定口播锚点，卡在所在**分句第一个字**被说出时入场，提前 3 帧。
- 连线「A 出现 → 线长 → B 出现」：源卡停稳 + 4 帧起画、14 帧长到、B 在线后才出现；相连两卡口播间隔 ≥ 38 帧，口播太密就减卡/拆镜/换无连线版式；镜长要放得下最后一张卡。
- 片头 = 口播第 1 句（5.1.5）：`vo.text` 等于第 1 句、时长 = 该句时长；按前缀/重点/转折/结论落拍，相邻拍与末拍到结束 ≤ 1.5s，不许静止。
- 卡面 ≤ 2 层字、填充 ≥ 50%、不出安全区；图片 `kw` 出自口播、`prompt` 含 `kw`；图片主导镜头 ≥ 1/3、纯卡连续 ≤ 2；饰线圆角 = 卡圆角 − 内缩。
- 闪烁：入场不透明度必须单调，`check:sequence` 逐帧检查，不降了又升、不单帧跳变。
