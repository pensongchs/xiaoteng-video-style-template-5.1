# 5.1 出片标准

基准标识 `5.1.1-2026-11-18`。完整强制条款以仓库根目录 `AGENTS.md` / `模板输出约束标准.md` 为准；本文件是同一标准的出片摘要。文案与时间码按当期变化，视觉基线保持。用户当前明确修改优先，其余条款继续生效。

5.0 的《买房先做减法再做加法》仍可作结构与节奏参考，但其暖白卡面、暖金当前词和沙金标题强调已被 5.1 取代，不能再当色彩标准。5.1 样张见 `previews/current/`。

## 1. 整体效果

1920×1080 横屏，正片 30fps，独立片头 50fps。清晰通透的中国住宅 / 城市实景作背景；前景是墨蓝·电光的中深透明玻璃卡，语义色只出现在描边、数字和图标上。深色卡内用冷白字，层次来自微渐变和语义描边，无颗粒、无扫光。中性白平衡，不用整屏黄绿、褐黄或青蓝滤镜。

普通卡片是规整圆角矩形，整组轻透视后停稳。不能把 38 种 MG 统一改成一种长方形清单。内容短时优先 5 款小卡组合。

## 2. 玻璃、色彩和文字

材质以 `tokens.ts / toneMat / glassMat / GlassEdge` 为准，默认色板 `inkBlue`。模糊为 `blur(18px) saturate(1.15)`。禁止暖白卡、土黄底、棕粉大面积填充和金色标题。

标题强调 `{词}` 使用 `HILITE`（`#BCD6FF` / `#1F56C4`）。卡内字走 CSS 变量 `--ink / --sub / --acc`。字体：片头江城律动宋 + Health；正片 PuHui Black 标题、Health Bold 正文及字幕。缺字体必须补齐。

字幕 40px，冷白 `#F5F8FC`，当前词冰蓝 `#9CC4FF`，墨蓝半透明底部胶囊，距底 44px，单行 ≤ 18 字，无下划线。详见 AGENTS.md 第 4 节。

## 3. 文本框内抠图

与 5.0 相同：按卡语义决定主体，真实照片质感，透明通道有效，边缘干净，`objectFit: contain`，与文字净距 ≥ 24px。不是白底矩形或截图。需要时用 `cardCutout`。

## 4. 连接线、箭头与空间运动

卡片先落位再连线。入场 16 / 18 / 20 / 12 帧，单调、无回弹。箭头复用 `GlassArrow`。整组轻推后固定。不得持续呼吸或镜尾还在变形。

## 5–6. 片头、开头与片尾

片头与正片可拆开制作，只交代做哪段就只出哪段。独立片头 50fps、默认纯画面。完整成片保留原声时钟，不得把正片整体后移一个片头长度。片尾固定 `outroHost`，使用小滕形象，互动靠姿势、气泡、弹卡，不加关注引导文字。细节见 AGENTS.md 第 7 节。

## 7. 选版与出片门槛

38 款共用材质与检查。短内容优先小卡。大卡只放图或图表，纯文字进小卡；不得选用已退役的纯文字重卡；户型用随包自绘素材；字阶取自 `CARD_TYPE` / `CHART_TYPE`；禁止近黑文字。细则见 AGENTS.md 第 3B 节。正式输出前必须 `npm run verify` 通过（含可读性/字阶），提交片头预览与正片审看，**用户批准后**才导出。机器检查通过不等于用户已经认可。

## 8. 缺素材时由 AI 完成取材

背景以视频为主、生成图为辅。无用户视频时，AI 联网寻找免费高清实景，优先航拍或有质感镜头，禁止随手手机拍。生成图只在加强表达的位置使用。列举和对比用图片框 + 文字标题。执行细节见 `正片/references/素材与生图规则.md` 与 AGENTS.md 第 8 节。
