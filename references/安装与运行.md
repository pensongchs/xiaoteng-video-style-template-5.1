# 安装与运行

Skill 根目录安装入口为 SKILL.md；输出约束以 AGENTS.md 为准；制作工程从 `node scripts/create-project.mjs <当期工程绝对路径>`建立，或续接用户当前工程。不包含开发者电脑绝对路径，不在Skill安装目录写成片。

Node≥22.18，npm；Remotion4.0.484、React19.2.7、TypeScript6.0.3按各自package-lock.json锁定，其他依赖以锁文件为准。沿用这个经过当前工程验证的版本组合，不因工具文档版本不同自动升级。准备依赖先运行本机 `~/.codex/shared-node-dependencies/ensure.mjs`；存在时复用，缺失时 `npm run setup`内部按锁文件/Node主版本/系统/架构建立全局共享组。项目只放node_modules链接，下载缓存集中在Codex目录。

字体不随代码仓库打包，`scripts/resources.json`含固定提交的下载URL及SHA256；setup自动下载到共享资源缓存，再准备当前工程字体。保留授权说明。缺字体、hash不符或网络失败时明确报错，不能用系统字体冒充定版。样例城市及小图只验证效果；正式片优先用户素材。

在当期工程执行：

```text
npm run setup
npm run verify
# 像素检查（正式交付建议）：
npm run verify -- --dom
```

`npm run verify` 已包含 TypeScript、风格指纹、颜色守卫、约束、定格冻结和镜头结构检查。不要跳过。gallery:stills 可输出代表帧与清单；必须实际查看，并与仓库 `previews/current/` 样张对照。首次换电脑还要渲染 Opening 及一段带声音的正式样例，检查字体、透明材质、图片、编码、原声/字幕时钟。Windows需要x64 Node与系统可运行的Chromium；Mac优先已有渲染浏览器。setup检查并准备Headless Shell；可用REMOTION_BROWSER_EXECUTABLE指定本机浏览器。FFmpeg/ffprobe可使用Remotion配套工具或已安装版本。

片头代码与完整工程内 `src/opening/`相同，50fps独立片头，完整工程按30fps和原声时钟叠加。设置openingConfig.enabled=true并重填本期配置后才启用；默认示例未自动启用到正式文案。完整成片沿用 Style51-Demo 入口（兼容别名 Style50-Demo）或用户已有正式入口，严禁把含完整原声的正片再向后推一个片头长度。

本仓库的机器与渲染检查不能代替任意电脑的实际环境验证。渲染失败先检查资源和浏览器，不能为通过安装而删掉模板材质或替换渲染器。

数字字体为本机合法Arial Bold（Mac/Windows自带路径或XT_ARIAL_BOLD），setup复制到当期工程；仓库不分发该字体。安装样例为50秒静音版式演示，字幕时间仅为演示参数，不能当作真实口播同步验收。正式出片脚本会拒绝把安装样例直接导出为「成片」；安装样例预览必须加 --preview，且不要使用成片文件名。渲染前会强制跑 verify，非法 props 与 --no-verify 会被拒绝。

开场音效可用根目录scripts/make-sfx.mjs合成，输入原声和 `{durationMs,beats:[{atMs,type}]}` 节点表（type=softBass/whoosh/tick/glassTap）；生成文件放当期public/episode，openingConfig中填写sfxSrc。只在完整视频混入，独立片头保持纯画面；核听确认不压人声。
