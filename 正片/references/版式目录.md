# 5.1 定版 · 版式目录

共 38 款正式版式：24 默认 + 9 新增 + 5 小卡组合（另有 10 款退役版式只保留渲染代码），均由 `src/style/layouts.ts` 登记，经 `ShotView / sceneOf` 渲染。画布与栏栅不变（1920×1080，12 栏，左 96，内容右界 1632，正文 y 248–880，底部 180px 字幕）。标题强调和图表高亮在 5.1 中为**冰蓝**（`HILITE` / `--acc`）；下文历史表格里写到的「金色」均应理解为该语义高亮，出片不得再使用沙金或亮黄。

完整选版决策表见根目录 `AGENTS.md` 第 6 节。

每种版式由 `src/style/layouts.ts` 给出「独立 MG 组」的矩形，再由 `src/style/archetypes.tsx` 填入组件。画布是 1920×1080 的 12 栏网格：左边距 96，栏宽 106，间距 24，内容右边界 1632。内容区从 y=248 到 y=880，底部 180px 留给字幕。

## 5.0 数据版式（组件在 `src/style/DataCharts.tsx` / `DataCharts2.tsx`，小样见 composition `DataChartSample` / `DataChartSample2`）
锚点键统一为 `draw`（说到这个词时开始画线/长柱/点亮），没填就按默认帧入场。尺寸规则：协调合理、不过小不过大，内容占矩形 55–75%，每镜一处金色。

| 版式 | 适合 | `data` 字段 |
|---|---|---|
| `lineReveal` | 逐年走势 | `pts[{x:'2019', v:1.52}] peak:拐点下标 unit vMin vMax drawDur?`（拐点亮点 + 96px 大数字） |
| `barGlow` | 3–4 项金额构成 | `bars[{k v hi?}] unit vMax barW?`（hi 只给一根，金色） |
| `rankBars` | 4–5 项排名 | `rows[{k v}]`（按从大到小，第一名自动金色） `unit vMax` |
| `waffle` | 每 100 人里… | `on:点亮格数 unit caption(可 \n) value:补充一句` |
| `balance` | 两方案总账 | `L/R:{k v s}` `tilt`：负数=左侧重（金色给重的一侧），建议 ±5–8 |

| `formulaCalc` | 计算过程 | `terms[{v k}] ops[] result unit note`（result 必须按公式算过） |

## 通用字段
- `kicker`：左上角的栏目行，例如「第一笔账 · 首付」。`city` 可选填，填了就显示为「杭州 · 第一笔账 · 首付」。
- `title`：标题。titleFloat、quoteStack、outroAir 三种版式不用这一行。用 `{…}` 包住的部分显示为金色，**每个标题最多一处金色**。
- `bg`：背景。`{src, video?, blur?, dark?, trim?}`，dark 一般取 0.4–0.6，5.0 实际压暗量 = max(0.13, dark−0.26)（4.5 为 max(0.22, dark−0.16)）。
- `at`：本镜从哪句口播开始（`{cue: 句子序号}` / `{text: '句中文字'}` / `{ms}`），时长自动算到下一镜开始，不再写 `sec`。
- `anchors`：动效锚点，键见 `音画同步与字幕.md` §2，值是对应短句起点、逐项关键词或字幕序号。
- `bareSubtitles`：本镜字幕去掉胶囊底，保留投影；默认使用磨砂胶囊。

## 新增一种版式时

这一节给模板维护者。做某一期视频时不要新增版式，不要改 `LayoutName`。塞不下就换下一个官方候选或拆镜。

1. 在 `layouts.ts` 里只用 `rect / cols / splitRows` 定义矩形，不要手写坐标。独立的组之间至少留 48px，左右相邻的组之间空出一栏。
2. 在 `archetypes.tsx` 里写 View，并注册到 `VIEWS`。新 17 款走 `sceneOf`，不要写进 `DEFAULT_LAYOUTS`。
3. 运行 `npm run stills`，DOM 检查要全部显示 ✓，再逐张看定格图。一期交付不要走这条路。

## 实际文案与磨砂渲染

当前样张在`previews/current/`。新卡通过`sceneText: {卡id: [各文本]}`、`textAnchors: {卡id: [锚点键]}`、`cardVisual: {卡id: 图形类型}`、`cardCutout: {卡id: 透明图片相对路径}`填入实际内容；可用图形有house/search/wallet/clock/calendar/subtract/add/lock/cross/leaf/plan/sun/building/tag/route/noise/shield。

`sceneOf()`按实际文本重排，删除空说明，图形与文字分别留空间。`slashCompare`显示规整双卡，`hexSteps`显示固定四步圆角卡，接口名称保持兼容。卡片、图形和连线共用轻透视平面。`GlassUnderlay`保证透视卡内真实磨砂；不要另写并行渲染器。

箭头统一复用`GlassArrow`：完整线身与头部、暖色玻璃金属渐变、细边高光、柔和厚度阴影；不能用字符箭头、单根细线或方块底座。连接必须在两端卡片落位后沿完整路径连续长出。

全部扩展卡支持 `cardCutout`与 `cardVisualBox`；完整语义文字通过 `sceneText`覆盖，文字时间码用 `textAnchors`。样张见根目录 `previews/current/`。
