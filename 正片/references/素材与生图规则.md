# 素材与生图规则

用户指定素材时按指定使用。没有可用视频素材时，由调用模板的AI主动联网寻找与逐镜文案匹配的高清实景视频，完成搜索、原页核对、下载、媒体检查与登记，不把取材任务交回使用者。已有素材不足也按此规则补齐。图片部分默认优先由AI按文案生成；当前模型不具备生图能力或生成工具不可用时，由AI主动联网查找匹配的高清图片。联网素材必须核实原页、使用授权、清晰度与实际内容，不编造来源，不使用搜索缩略图或有水印预览图。视频须≥1920×1080高清横屏，优先中国城市或住宅实景，时长覆盖trim与镜长，背景清晰、白平衡中性、无水印。相邻镜避免同一段背景与同一构图；同一视频不同trim可用，不能在相邻镜重复。同一期优先5类场景轮换，按文案适配，不为凑数用无关空镜。静图背景通常≤1/3。

生成照片：当期语义主体、中国住宅语境、中性日光、真实自然色、清晰通透、单一视觉重心；无文字、数字、招牌、logo、水印，无黄绿罩染、褐色滤镜、过度HDR和虚假楼盘标识。照片用于MediaFrame，按框比例生成；抠图单独生成并要求真实透明背景。卡内使用抠图与几何槽位见根目录出片标准第3节。

透明图保留alpha，长边通常640–1000px；照片长边1280–1600px，JPEG约80–88质量。不能把透明图转成白底JPEG。检查图像模式、alpha极值、半透明边缘、裁切、文字伪影、图文净距与手机可读性。每镜可用语义图形补充理解，但不强制每个图表再叠照片。

素材存当期 `public/media/`并登记页面URL或生成模型、提示词、用途、授权与示意属性。生成图不能证明真实楼盘、价格或居住条件；标记留在制作资料，实际有混淆风险时在主图内简短写“示意”。品牌卡通素材可固定复用，其余资源不随意替换。

画面通透靠选材、中性明暗和局部文字保护；`bg.blur=0`，不整屏模糊。正片使用当前Backdrop参数，片头用 039 ASCII 渐变背景（5.1.5，`npm run setup` 自动下载适配）；不要套旧压暗公式。仓库演示资源只验证模板，不代表正式选材已经完成。

联网图片长边至少1600px（小尺寸透明抠图按实际显示像素保证清晰），从原图页下载；需要抠图时优先寻找有真实alpha的高清素材或使用可用的去背景工具处理并检查边缘。不能用白底矩形替代透明图。视频逐条用ffprobe验证分辨率、帧率与时长，抽帧确认内容和无水印；图片核对原始尺寸和清晰度。无法取得符合要求的素材时说明具体缺口，不能静默降为低清素材。

## 5.1.5 图片动效组件的生图（按口播关键词）

- 图片组件（`imageFrame3D` / `imageSwap` / `imageGrid` / `imageCutout`）里每张图都写 `kw` 与 `prompt`：`kw` 必须是**本镜口播原词**，`prompt` 必须包含 `kw`，并带「中国住宅语境、中性日光、真实摄影质感、冷静偏蓝自然色、无文字、无logo、无水印」。暖色调图只在口播语义就是「暖」时用，并压低饱和。
- `npm run images:plan` 列出镜头表里全部图片的 `{镜, 版式, kw, prompt, src, 是否已有}`；`--json` 输出交给生图工具逐条生成，产物放 `public/<src>`，登记到 `public/media/gen/img515/ledger.json`（模型、提示词、用途、尺寸）。
- 生成后跑 `npm run plan:check`：缺 src/kw、prompt 不含 kw、kw 不在本镜口播里都会拦下。
- 尺寸：图框照片长边 1280–1600px（按框比例 16:9 / 4:3）；抠图保留真实 alpha。
- 节奏：每期（不计片尾）图片主导镜头 ≥ 1/3，纯卡片镜头最多连续 2 个。
- 随包样例图（`public/media/gen/img515/`）为模板演示用生成图，正式出片按本期口播重新生成。
