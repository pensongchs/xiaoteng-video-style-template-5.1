# 排版底层约束

共用视觉参数见根目录 `AGENTS.md` 与 `references/出片标准.md`。5.1.1 共 38 款正式版式；内容短优先小卡组合，条目须落在各版式容量内。1920×1080、12栏：左96，栏宽106、沟24，内容右界1632；正文y248–880，底部180px字幕。独立MG组净距≥48px，图形与文字≥24px；连接件≥24px，连接端点距卡外4–8px。身份牌独立右上安全区右34、顶28。

卡片按语义容量分配，正文多行行高≥1.3，不能填长文后压成小字。标题大而清楚、正文深墨、必要单位完整；不留空说明框。每个版式使用 `layoutRects`和正式组件。普通卡片圆角矩形与轻透视；户型、楼体、道路等保留语义轮廓。

连接必须在两端落位后连续绘制，卡片与线共用平面；空间整组轻推后停稳。禁止穿字、穿卡、断裂和提前显示独立节点。户型墙体、开门弧、三线窗、尺寸、朝向、动线按 `floorplans.ts`和当前几何检查，不让动线穿墙。

运行约束检查、字体实测与DOM检查；还必须看代表帧及动作中间帧。机器检查不覆盖所有艺术质量与语义正确性。


## 5.1.2 卡面内容守卫

卡面不得有占位字；大圆（≥240px）/大卡里不能只有 ≤2 字且无图；长条卡（宽 ≥600px 或 ≥3:1）要带图标或补充行，内容实占宽度 ≥ 40%；卡面填充只用墨蓝·电光玻璃色（半透明、不棕、不纯灰）。阈值见 `src/style/content-guard.ts`，检查见 `npm run check:cards` 与 `verify --dom`；详见 AGENTS.md 第 3C 节。
