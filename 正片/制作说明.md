# 5.1 定版（墨蓝·电光 + 小卡组合）· 正片

先读根目录 `AGENTS.md` / `模板输出约束标准.md` 和 `previews/current/` 样张，再读 `references/版式目录.md`、`文案匹配机制.md`、`素材与生图规则.md`、`音画同步与字幕.md`。母工程为 `template/`，正式镜头只走 `ShotView / sceneOf`。默认色板 inkBlue，字幕为 v2 令牌，内容短优先 5 款小卡组合。

按原声绝对时钟填写镜头表、锚点、完整文案与素材。保持共用组件，禁止手写颜色。运行 `npm run verify`（必要时加 `--dom`）。先提供预览，用户批准后再导出完整视频。素材与成片都放当期目录（在模板安装目录之外）。
