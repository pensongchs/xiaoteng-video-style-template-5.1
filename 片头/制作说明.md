# 片头制作说明

片头覆盖口播第 1 句，画面保留主题大字、抠图和结尾红章。右上可以留账号身份。片头全程不显示字幕，也不加底部小字、解释性副标题、标签或角标。原始口播、首句字幕和时间码完整保留，整片从片头结束后的首条正文开始显示字幕。

## 文字与动效

- 采用深蓝 ASCII 背景、自然冷调透明抠图和冰蓝银标题。左侧以前缀和重点两个层级落字，右侧用主题抠图接力。转折时保留图文换位，前面主题字淡出，为右侧转折和收句让出位置。
- 转折、必要引导词、红章左对齐，各占一行。用口播原话的短词排版，标题会按宽度收字。除非删掉会误解原句，省略独立的引导词。
- 红章只盖一次，跟着 `timingMs.verdict` 对应的原话起音落下，约 180ms 压实。深朱红底、细双边、浅字、小角度和轻阴影。短词收窄印面，长词自动适配，最多 9 字。章与转折、图像分区，注意手机预览时的字距与安全边界。

## 配置与检查

`openingConfig.ts` 的 `vo.text` 填首句，`vo.startMs` / `vo.endMs` 填真实时间码，片头时长按首句计算。把原话关键词填进 `text.prefix/focus/turn/verdict`，把词起音填进 `timingMs`，用 `vo.anchors.verdict` 绑定盖章词。默认启用 `stamp`，需要保留引导词时填写 `stamp.lead.text/ms/anchor`。相邻语义拍间隔及末拍到结束不超过 1.5 秒。随包背景由准备脚本取得，透明主体用与每期口播匹配的素材。

独立入口为 `assets/workspace/src/Opening.tsx`，整片入口为 `正片/template/src/opening/Opening.tsx`，两处共用同一排版与动作。独立片头为 1920×1080、50fps、纯画面。整片按原声时钟叠加，正文默认 30fps。渲染前运行 `npm run verify`，查看首帧、转折、落章和切回正文的第一句字幕。
