# 5.1.5 片头制作说明

视觉与动作先读根目录 `references/出片标准.md`第5节，样图见 `previews/current/` 的片头关键静帧与短预览。默认入口为 `assets/workspace/src/Opening.tsx`，配套 `openingConfig.ts / openingBeats.ts / AsciiGradientBackground`（039，`npm run setup` 时由 `scripts/fetch-ascii-bg.cjs` 按 sha256 从 react-bits 下载并适配，生成文件不入库）；`EpisodeOpening`为同入口别名。5.1.5 起按 skill「小滕片头风格模板」：深蓝 ASCII 渐变背景 + 径向压暗；左侧「前缀/重点」冰蓝字组，右侧三张住宅抠图接力；转折时 580ms 交换（文字走上弧到右、缩到 .5，房子走下弧到左）；结论词暖金大字（暖金只许出现在片头）；右上身份标识。不从空白重新设计风格。

从原声第一句或用户明确指定区间读取真实逐字时间码，转换为当前fps相对节点，不能挪动片头/正文分界。独立片头1920×1080、50fps、纯画面；完整视频按原声时钟叠加，正文默认30fps，不把50fps片头先拼在完整原声前面。

配置包括完整屏显文本、主题卡片图片、skyline、语义节点、开头终点和总帧数；更换主题必须同步所有字段，不只改期名。主题主体为透明抠图；每期优先用户已有有效素材，再按语义制作，避免无关主体。身份标识右34px、顶28px。进入正片的约7秒内继续设计住宅类型/主题对象切换与独立红章，不把节奏只做在片头2秒。

复制到当期工程后运行 `npm run setup`、`npm run check`，渲染首帧、转折、重点落版及接缝帧，核对字体、透明边缘、图文间距和手机可读性。渲染 `Opening`导出独立片头；整片复用本组件。依赖与字体见根目录 `references/安装与运行.md`。不在安装目录制作。

## 5.1.5 片头 = 口播第 1 句

片头只覆盖本期口播**第 1 句**：`vo.text` 必须等于第 1 句（正片 `plan:check` 用 `episode.json` 第一条字幕核对），片头时长 = 该句时长（`vo.endMs − vo.startMs`），不跨到第 2 句。任何画面停留 ≤ 1.5s。模板 `正片/template/src/opening/` 与本工程 `assets/workspace/src/` 的 `Opening.tsx / openingConfig.ts / openingBeats.ts` 保持同步。

## 5.1.3 片头节拍规则（沿用）

片头不是「几个固定节点后停住」：口播每说到一个关键词就换一拍——关键词文字 + 换主题卡/配色一起换。`openingConfig` 里：`vo.text` 是片头口播原文（片头文字必须逐句取自它）；基础四拍（`text.prefix/focus/turn/verdict` 对应 `timingMs`）之后，用 `extra[]` 追加拍，每拍写 `ms`（该口播短语起点）、`kw`（关键词）、`anchor`（口播短语）、`src`（换一张主题卡）。

规则（`src/openingBeats.ts` 的 `openingFaults`，`npm run check:beats` 与正片模板的 `npm run plan:check` 都会跑，纯静态不渲染）：第 1 拍在 0ms；拍点严格递增；相邻拍间隔 ≤ 1500ms，最后一拍到片头结束 ≤ 1500ms（不许一个画面停住不动）；每拍有关键词、不许占位字；追加拍必须换 `src`；有逐字时间码时拍点 ≈ 对应口播短语起点（≤ 60ms）。7 秒的片头至少要有 5 拍左右，不是 3 个节点。
